* If GitHub strips SVG animation, replace the header/bow with static PNGs (upload them to your repo or an image host) and update the `src` attributes.
* To change the lavender hue, edit the hex colors in the SVG blocks (`#E9D5FF`, `#D8B4FE`, `#7C3AED`).
* Want a different bow image? Replace the inline SVG with:

```html

```
